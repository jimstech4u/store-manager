# store-manager

Manager-facing web app, built on the `@academix-admin/*` package family (navigation-stack,
state-stack, navigation-bar, sidebar, header — see `academix-ui/`).

Scaffolded to match `academix-web`'s toolchain: Next.js App Router, TypeScript strict, the same
ESLint flat config. Product scope is planned in `ACADEMIX_PLAN.md`.

## Getting started

```bash
npm install
npm run dev
```
